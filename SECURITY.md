# Security policy

Regex Playground is a static site. It has no server and no accounts, and it stores nothing: the
pattern and the text you type stay in your browser, except for what you put in a share link yourself.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub's security advisories](https://github.com/FabianoArthur/aula-1/security/advisories/new)
with steps to reproduce. You can expect a first answer within a week.

In scope: script injection through a pattern, test text or share link, bypasses of the
Content-Security-Policy, and anything that makes the page send data somewhere.
